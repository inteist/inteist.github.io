/// Counts the words in a note.
fn word_count(text: &str) -> usize {
    text.split_whitespace().count()
}

fn main() {
    let note = std::fs::read_to_string("notes.md").unwrap();
    println!("words: {}", word_count(&note));
}

Print and export

Print and PDF export

Print through the native dialog, or export the entire document as one continuous PDF page. Tables and code blocks stay together instead of splitting across pages.

  • Print Document The native macOS print dialog. ⌥⌘P
  • Export Document as PDF One continuous page, without page breaks.

Continuous-page PDF export requires macOS 11 or later.

Files and saving

Open a file or a vault and start writing

Open a single .md file from Finder, run paperloom notes.md in the terminal, or open a folder as a vault for linked notes and file search.

  • Edits save automatically to the original Markdown file.
  • External changes are detected and reloaded.
  • A prompt appears if reloading would discard unsaved work.
  • Opening a standalone file does not add app settings or session files to its folder. 
~/proj $ paperloom README.md
MD From Finder Double-click a .md file, or choose Open With → PaperLoom.

Under the hood

Blazing fast & lightweight

A fast and efficient Rust backend handles data processing and formatting.

9 MB The whole package

  • No bundled browser

    The 9 MB package uses Tauri and the system webview rather than bundling a browser.

  • Rust backend

    Rust handles file operations, search, and native app functions efficiently.

  • Reused views

    The editor reuses document views when switching tabs to reduce repeated rendering work.
